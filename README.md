# Soru Takibi – iPhone sürümü

Öğrencinin haftalık ders programına göre her gün çözdüğü soru, doğru ve yanlış sayılarını girip
raporu resim olarak WhatsApp'tan gönderdiği web uygulaması.

**Kullanım:** Adresi iPhone'da Safari ile açın → Paylaş → **Ana Ekrana Ekle**.

- Veriler sadece kullanan kişinin telefonunda (Safari hafızasında) tutulur; buraya gelmez.
- Ayarlar'dan arada bir **yedek dosyası** alın. Yedek, Android sürümüyle aynı yapıdadır.
- Güncellemede `sw.js` içindeki `CACHE` adı değiştirilir.
